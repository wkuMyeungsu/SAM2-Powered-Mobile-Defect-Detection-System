# 파트 간 주고받는 데이터

구현 전에 경계마다 형식을 합의해 이 폴더에 적는다. 합의되면 파일 하나로 정리하고 담당자 둘이 확인한다.

| 경계 | 보내는 쪽 → 받는 쪽 | 정할 것 | 문서 |
|---|---|---|---|
| 프레임 입력 | 휴대폰 → gateway | 전송 방식, 이미지 형식, 해상도, 주기 | 미정 |
| 전처리 입력 | gateway → preprocessing | 요청 형식, 이미지 인코딩 | 미정 |
| 추론 입력 | preprocessing → inference | 요청 형식, 이미지 인코딩 | 미정 |
| 추론 결과 | inference → visualizer | 원형도, 판정, 마스크 표현 | 미정 |
| 재수신 | visualizer → gateway → web | 마킹된 프레임 전달 방식, 판정 결과 | 미정 |
